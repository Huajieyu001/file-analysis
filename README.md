# CleanDup — 文件去重工具

PySide6 桌面客户端，专为 60TB+ 大容量存储去重设计。原生表格渲染，流畅不卡。

## 核心思路

三段式逐步求精，避免 O(n²) 全量比对：

```
所有文件
  ↓ Pass 1: 按文件大小分组（大小唯一的直接排除，覆盖 99%）
同大小文件
  ↓ Pass 2: 快速哈希（只读文件头 8KB，XXH128）
同快速哈希文件
  ↓ Pass 3: 完整哈希（流式读完整文件，可选跳过）
重复组
```

快速哈希只读 8KB 文件头，省去 HDD 寻道，比读首尾 128KB 快 5 倍以上。XXH128 碰撞概率极低（< 2^-128）。

## 功能标签页

| 标签页 | 功能 |
|--------|------|
| **重复组** | 展示所有重复文件组，按大小/路径/浪费空间排序。点击展开文件详情，勾选删除。支持批量框选、Shift 多选、键盘 ↑↓ 导航 |
| **搜索结果** | Everything 风格即时搜索，输入关键字过滤已索引文件，右键打开位置/复制路径/删除 |
| **文件夹比对** | 选择两个文件夹，快速哈希比对找出重复对，一键删左/删右 |
| **本地查重** | 输入一个文件夹，查找其中文件在磁盘其他位置是否有重复。支持两种模式：删除本地（留别处）/ 保留本地（删别处） |
| **清理空文件** | 扫描所选盘符中的 0 字节文件和空文件夹，一键清理 |

## 使用

```bash
pip install PySide6 xxhash send2trash
python app_qt.py
```

或下载 `dist/CleanDup.exe` 直接双击运行。

- 启动即自动全量扫描，无需手动点击
- 进度条平滑动画 + 百分比实时显示
- 扫描完成显示耗时统计（总耗时 / 快速Hash耗时 / 扫描文件耗时）
- 所有删除操作进回收站，可恢复
- 设置弹窗：扫描选项（全量哈希、最小大小）+ 文件后缀（大类/子类/单后缀三级勾选，支持一键扫描所有文件）
- 底部实时显示已选盘符总容量和可用空间

## 项目结构

```
file-analysis/
├── app_qt.py           桌面客户端入口（PySide6）
├── config.py           配置常量（DB路径、哈希参数、过滤规则）
├── database.py         SQLite 层（WAL 模式、索引、增量查询）
├── scanner.py          文件遍历器（生成器模式，内存友好）
├── hasher.py           哈希计算（XXH128 快速哈希 + 完整哈希）
├── deduplicator.py     去重编排（三段式 + 多线程并行）
├── reporter.py         格式化工具（文件大小显示）
├── requirements.txt    依赖
└── settings.json       用户配置（后缀、最小大小等，自动保存）
```

## 配置

客户端设置弹窗可配置：
- **扫描选项**：全量哈希开关、最小文件大小（MB）
- **文件后缀**：视频/图片/音频/文档四大类，大类→子类→单后缀三级勾选，支持"扫描所有文件"一键切换

配置自动保存到 `settings.json`，修改后自动重新扫描。

## 打包

```bash
pip install pyinstaller
python -m PyInstaller --onefile --windowed --icon=app_icon.ico --add-data "app_icon.ico;." --name "CleanDup" app_qt.py
```
输出在 `dist/CleanDup.exe`（约 50MB，自包含，无需 Python 环境）。
