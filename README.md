# 文件去重工具

桌面客户端，专为 60TB+ 视频存储去重设计。PySide6 原生渲染，流畅不卡。

## 核心思路

不是比较所有文件对（O(n²) 不可能），而是三段式逐步求精：

```
所有文件
  ↓ Pass 1: 按文件大小分组（大小唯一的直接排除，覆盖 99%）
同大小文件
  ↓ Pass 2: 快速哈希（只读首尾各 64KB，XXH128）
同快速哈希文件
  ↓ Pass 3: 完整哈希（流式读完整文件，可选跳过）
重复组
```

XXH128 哈希速度 >10GB/s，128 位碰撞概率极低（< 2^-128）。

## 增量机制

首次扫描后文件路径/大小/mtime/哈希全部存入 SQLite。后续扫描只需检查 mtime 是否变化：

- 文件未改 → 跳过，哈希复用
- 文件新增/修改 → 重新走三段式
- 文件已删除 → 标记移除

60TB 数据首次扫描后，后续增量更新通常只需几分钟。

## 使用

```bash
pip install PySide6 xxhash
python app_qt.py
```

- 独立桌面应用，不需要浏览器和服务端
- 启动即自动增量扫描
- 搜索框即时过滤，类似 Everything 的体验
- 表格原生虚拟滚动，渲染万行不卡
- 重复组点击展开，勾选删除，支持右键复制路径
- 设置弹窗可视勾选后缀过滤

## 项目结构

```
file-analysis/
├── app_qt.py           桌面客户端入口（PySide6）
├── config.py           配置常量（数据库路径、哈希参数、过滤规则）
├── database.py         SQLite 层（WAL 模式、索引、增量查询）
├── scanner.py          文件遍历器（生成器模式，内存友好）
├── hasher.py           哈希计算（XXH128 快速哈希 + 完整哈希）
├── deduplicator.py     去重编排（三段式 + 多线程并行）
├── reporter.py         结果输出（CSV / JSON 导出）
├── requirements.txt    依赖
└── settings.json       用户配置（后缀勾选自动保存）
```

## 性能参考

| 数据规模 | 首次扫描（快速模式） | 增量更新 |
|---------|-------------------|---------|
| 20 万文件 / ~30TB | ~6 小时 | ~10 分钟 |
| 5 万文件（200MB+ 过滤后） | ~1 小时 | ~2 分钟 |

快速模式仅用文件首尾 128KB 判定重复，速度提升 10-20 倍。
勾选"全量哈希"可启用精确模式，但耗时显著增加。

## 配置

编辑 `config.py`：

```python
MIN_FILE_SIZE_MB = 200    # 小于此值的文件跳过
WORKER_THREADS = 4        # 并行线程数
```

后缀过滤通过客户端设置弹窗配置，保存在 `settings.json`。
